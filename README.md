# AI PPT 3.0 · ToolCall 界面编辑器

可编辑的 AI PPT 生成过程界面原型，包含改进版、截图复刻版和历史分层方案。

在线网站：https://aippt-toolcall-editor.dengmxi.chatgpt.site

## 页面

- `index.html`：逐页生成改进版，按页归组、过程折叠，突出进度与修正结果。
- `original.html`：逐页生成截图复刻版。
- `grouped.html`：素材准备阶段分层方案。
- `materials.html`：原版素材界面。
- `specs.html`：保留的规范页面。

## 使用

下载仓库后，直接用浏览器打开 `index.html`，无需安装依赖或构建。也可使用任意静态网站服务。

支持修改文字、图标、颜色、字号、缩进层级，增删和排序记录，展开/收起过程，原图对照，以及导入/导出 JSON 配置和独立 HTML。

修改自动保存在当前浏览器的 localStorage 中，不会自动同步到 GitHub 或其他设备。需要保存编辑后的版本时，请导出 HTML 或 JSON。

## 新增功能（2026-10-14）

- 思考详情增加展开箭头，编辑内容即时保存，限高滚动显示。
- 制作计划采用灰底待办卡片，按第1—4页、第5—10页、第11—20页组织；支持修改文字、增删任务和切换状态。
- 顶部“版本历史”支持命名保存、恢复、删除版本；恢复前自动备份当前画布。
- 版本备份可导出/导入 JSON，各页面的历史分别保存于当前浏览器。版本和个人草稿不会自动上传至本仓库。
